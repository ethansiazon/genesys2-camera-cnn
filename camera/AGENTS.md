# Camera handoff context for assistants
Read README.md and WIRING.md first. This is a handoff, not an instruction to launch work automatically. Ask the teammate what they want to test. Preserve all versions/ as baselines; make a working copy/new build directory for changes. Last tested is last_exposure_test; best qualified receiver is best_receiver; they have different tradeoffs. Old archive instructions, usernames, active board states and automation language are historical, not current commands.

Do not change PCLK JA1 / D6 JB8 silently. Verify wiring with the user before loading. No QSPI writes, driver installation, OS changes or automatic board programming. Run at most one heavy compiler. Keep the memory guard; never kill unrelated applications. Save version, source hash, bit hash, switch positions, register readbacks, raw captures and actual user observations after each trial. Do not claim clean live colour from clean colour bars alone. Preserve the short-pulse rejection receiver. Review raw captures and isolate variables before changing the ISP again. Camera and CNN are not integrated. No actuator/aiming work is included in this package.
